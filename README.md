# NBRP Field Report V1

Mobile-first field report web app for turning job-site photos, project information and notes into customer-ready reports.

## V1 scope

- App header keeps the NBRP logo and NBRP GLOBAL on one row, with no Field Report line underneath.
- Home introduction uses the requested three-level hierarchy.
- Project, Date / Reference Number, Prepared By / Company and Report Title fields remain separate.
- Photos & Notes uses the requested capitalization.
- PDF footer is contained inside each report page and does not create an extra page.
- UI language selector supports exactly 10 languages.
- User-entered report content is never translated or modified by the UI language selector.
